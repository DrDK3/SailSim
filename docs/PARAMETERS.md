## Squib types (`data/boats/squib/variants.json`)

Each type is a hull build plus a sail package. The class is a strict one-design (same hull form and sail plan
for every builder, C10), so a type changes only the parameters listed; everything else is as above. The Rondar
type is the calibrated default.

### Rondar Squib (the modern standard)

Hull: Rondar Raceboats, Mark 3 mould (2016-2024). Sails: Earlier sail designs (the simulator's calibrated default).

Rondar build (2016-2024): self-draining cockpit, so water shipped over the rail runs out through the transom. Earlier-design sails. The simulator's calibrated default.

No changes from the parameters above.

### Classic Parker or Hunter hull (the traditional fleet)

Hull: Hunter Boats (sail numbers 158-724) and Parker Sailboats (1997-2010). Sails: Earlier sail designs (the simulator's calibrated default).

Hunter (1970s-1997) or Parker (1997-2010) build: same hull form, but the cockpit is not self-draining - water shipped in gusts or chop stays aboard until the crew bails it, making the boat heavier and more tender. Assumed 15 kg over the class minimum (estimate).

| `mass.aboveMinimum` | 15 | kg | E | estimate | Older GRP hulls are often heavier than new ones (absorbed water, repairs, older fittings). Not measured: weigh the boat and change this |
| `cockpit.selfDraining` | 0 | - | S | C9, C10 | Self-draining cockpits came with the Rondar build; earlier boats keep the water until it is bailed (a few have been fitted with the new floor moulding, the 'hybrid Squib') |

Rondar hull with the 2024 sail designs: a flatter foot lets the jib and main sheet closer to the centreline, a wider groove upwind and a fuller main downwind (maker's claims; the size of each effect is an estimate).
